# Bank Customer Churn Analysis

## Project Overview
This project focuses on analyzing bank customer churn to identify customer behavior, understand churn patterns, and generate meaningful business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI

## Project Structure
- Dashboard – Power BI Dashboard
- Dataset – Dataset used for analysis
- Python_Analysis – Python analysis and data cleaning
- SQL_Queries – SQL queries
- Visualizations – Charts and graphs

## Key Analysis
- Customer Churn Analysis
- Churn Rate Analysis
- Customer Segmentation
- Data Visualization

## Objective
To analyze customer churn patterns and provide insights that can help improve customer retention.
